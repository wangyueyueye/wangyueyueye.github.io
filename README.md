# 月之音

本地优先的 ASMR 作品库与字幕播放器。

- 网页 / PWA：https://wangyueyueye.github.io/
- Android APK：https://github.com/wangyueyueye/wangyueyueye.github.io/releases/download/android-v2.4/yuezhiyin-v2.4.apk

音频、字幕、封面和播放进度只保存在手机浏览器本地，不会上传到这个仓库。
首次打开 APK 需要联网加载 App 外壳，之后可离线使用。

安装 APK 后，原来的 `http://电脑IP:8765` 数据不会自动迁移，因为浏览器按网址隔离存储；请在新的 HTTPS 网址里重新导入原始文件。
