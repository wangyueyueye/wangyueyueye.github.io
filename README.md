# 月之音

完全离线的 Android ASMR 播放器。

## Android 离线 APK

下载：https://github.com/wangyueyueye/wangyueyueye.github.io/releases/download/offline-v3.0/yuezhiyin-offline-v3.0.apk

- Android 7.0+
- 不需要 Chrome
- 所有界面和逻辑打包在 APK 内
- 首次打开即可离线使用
- 音频、字幕和进度只保存在手机本地，不会上传

注意：离线 APK 使用自己的本地存储 origin，和旧网页/TWA 的数据不互通，需要重新导入一次原始文件。
